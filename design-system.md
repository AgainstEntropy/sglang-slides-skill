# SGLang / RadixArk slide design system

> Source: tokens reverse-engineered from the official RDXA deck
> (`sglang-happyhour-7min.pptx`, 2026-06 NYC happy hour), with the layouts validated on the
> sglang-diffusion Amazon talk (2026-08).
> Code: [`sgl_deck.py`](sgl_deck.py) (python-pptx wrapper; the tokens are constants there).

## 1. Canvas and grid

| | |
|---|---|
| Canvas | 16:9, **13.333 × 7.5 in** (`LAYOUT_WIDE`) |
| Margins | **0.6 in** left and right (`MX`); content width **12.133 in** (`CW`) |
| Vertical zones | eyebrow y=0.38 → title y=0.66 → **content starts at y≈1.55** → bottom takeaway/placeholder line y≈6.1–6.7 → page number y=7.08 |
| Element spacing | 0.3–0.5 in, kept consistent within a deck |

## 2. Colors

| token | value | use |
|---|---|---|
| `INK` | `#1A1A1A` | Body text, dark panel fills |
| `SUB` | `#555555` | Secondary text (explanations, caption body) |
| `MUT` | `#888888` | De-emphasized text (figure notes, page numbers, placeholders) |
| `LINE` | `#DDDDDD` | Hairline rules, card outlines |
| `PANEL` | `#F5F5F5` | Card / panel fill |
| `ACC` | `#C0492C` | **Primary accent**: eyebrow, key numbers, punchline, highlighted words |
| `ACC2` | `#2A7A6A` | Secondary accent: positive / quality / "safe" semantics (lossless, default, …) |
| `TINT` | `#FBEFEA` | Light ACC background (the side with a cost / that needs attention) |
| `TINT2` | `#EAF3F0` | Light ACC2 background (the safe / lossless side) |

Rule: **ACC appears at most 2–3 times per slide** (the eyebrow does not count). Fully saturated
color blocks are for diagrams only; highlight text with color alone, never with a background fill.

## 3. Type and sizes

| Element | Spec |
|---|---|
| All text | **Calibri** (safe-list font, ships with Office; swap for Inter on web exports) |
| Code | **Courier New** |
| Eyebrow | 12 pt bold ACC, all caps, **+3 pt letter spacing** (`spc=3`) |
| Slide title | 28 pt bold INK (drop to 26 if it does not fit on one line) |
| Title-slide headline | 40 pt bold |
| Big stat number | 34–40 pt bold ACC |
| Body / bullet | 12–13.5 pt |
| Card title | 13.5–15 pt bold |
| Figure note / caption | 10–10.5 pt MUT (italic means "to be filled / schematic") |
| Page number | 10 pt MUT, bottom right, omitted on the title slide |

## 4. Layout patterns (pick one main pattern per slide, do not mix)

Every pattern has a worked slide in [`examples/example-deck.pptx`](examples/), generated by
[`examples/make_example.py`](examples/make_example.py).

| pattern | use | lib API |
|---|---|---|
| **Title** | First slide: logo + 40 pt headline + one-line subtitle + speaker/venue | `image` + `text(align="center")` |
| **Stat row** | A row of big numbers (3–4), with bullets underneath | `stat_row()` |
| **Lead bullets** | "**bold noun** — gray explanation" list, 3–5 items | `lead_bullets()` |
| **Comparison table** | Two worlds side by side; header row on PANEL fill, right column may use ACC | `table()` |
| **Cards grid** | Equal cards in a 2×3 / 1×4 grid; **at most one** highlighted with TINT fill + ACC outline | `card()` + `para()` |
| **Two-panel split** | A two-way taxonomy: TINT2 block left, TINT block right | `card()` ×2 + `bullets()` |
| **Diagram** | Bullets on the left (w≈6–6.5), schematic on the right; the diagram is box/arrow/tri | `box` `arrow` `tri` `ellipse` |
| **Code image (carbon)** | Code blocks are always **light** cards rendered by carbon.now.sh (one-light theme, traffic lights, hairline border); `scripts/carbonize.py` produces the image in one command; fall back to `code_panel()` only when offline | `scripts/carbonize.py` + `image()` |
| **Close** | QR + code + thanks | `qr()` + `code_panel()` |

General rules:
- **One punchline per slide**: its own line, bold ACC, 14–15 pt, at the bottom of the content area.
- Body text is left aligned; only the title slide and a centered closing line may be centered.
- Diagram colors: neutral blocks in `#888888`/`PANEL`, **the one block the eye should land on in ACC**,
  positive / terminal blocks in ACC2; text inside the diagram is 9.5–10.5 pt.
- Placeholders (numbers to measure, assets to drop in): **italic MUT** text or an empty card with a
  **dashed LINE border**, so "not filled in yet" is obvious at a glance.
- Avoid: gradients, shadows, 3D, icon libraries, underlined titles, **decorative color bars of any kind**,
  code blocks longer than 6 lines, a slide that is nothing but text.

## 5. QA process (after every build)

```bash
# 1. Structural validation (the validator from Claude's pptx skill; skip if absent —
#    opening the file in PowerPoint validates it too)
uv run --python 3.12 --with lxml --with defusedxml --with python-pptx --with pillow \
  python <pptx-skill>/scripts/office/validate.py deck.pptx

# 2. Content QA: dump the full text, look for missing slides / leftover placeholders
uvx --from "markitdown[pptx]" markitdown deck.pptx | grep -iE "lorem|TODO|\[insert"

# 3. Visual QA (LibreOffice is installed on this machine): pptx → pdf → one png per page, then look at each
"/Applications/LibreOffice.app/Contents/MacOS/soffice" \
  --headless --convert-to pdf deck.pptx
uv run --python 3.12 --with pypdfium2 --with pillow python -c "
import pypdfium2 as p
pdf = p.PdfDocument('deck.pdf')
[pg.render(scale=1.4).to_pil().save(f'slide-{i+1:02d}.png') for i, pg in enumerate(pdf)]"
# Watch for: text overflow, overlapping elements, gaps under 0.3 in, unintended shape shadows
```

> Render with pypdfium2 rather than poppler/pdftoppm — the wheel bundles pdfium, so there is no
> dependency on Homebrew dylibs.
>
> **Popup troubleshooting**: MDM on this Mac stamps `com.apple.quarantine` on files downloaded by
> Homebrew, which makes the system show a "Not Opened" dialog when they are loaded (cleared in bulk
> on 2026-08-13). If a newly installed package triggers it again, rerun:
> `xattr -dr com.apple.quarantine /opt/homebrew/Cellar`; for read-only files that refuse to clear,
> `chmod u+w` temporarily, delete the attribute, then restore; use `xattr -s -d` for symlinks.
